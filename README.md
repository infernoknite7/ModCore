# ModCore (Paper 1.21.11)

Combat timer (15s), ban/mute, vanish, and 3-strike warnings in one jar.

Build: `mvn package` -> `target/ModCore.jar` -> put in `plugins/`.

Commands: /ban /unban /mute /unmute /warn /warnings /clearwarnings /vanish (/v) /modcore reload
Durations: 30m, 2h, 1d, 1w, perm
Permissions: modcore.ban, modcore.mute, modcore.warn, modcore.vanish, modcore.vanish.see,
modcore.admin, modcore.combat.bypass (ops get everything except bypass by default)
